## 📂 Assignment Questions

### 1. Pass or Fail Counter

A program that:
- Checks whether students have passed or failed based on their marks.
- Counts the number of passed and failed students.
- Creates a list containing passing marks using list comprehension.

### 2. Safe Average Calculator

A function that calculates the average of numbers while safely handling a `ZeroDivisionError` when an empty list is provided.

### 3. Daily Step Tracker

A program that:
- Generates random step counts for 7 days.
- Stores the daily steps in a list.
- Finds the highest and lowest step counts.
- Calculates the average number of steps.

### 4. Student Class

A simple `Student` class demonstrating:
- Classes and objects
- `__init__`
- Type hints
- Instance attributes
- Methods
- `__str__`
- Average marks calculation

### 5. Import and Use a Module

A program using Python's built-in `math` module to calculate:
- Area of a circle
- Circumference of a circle
